# Status Saver - Video Saver 🌟

A sleek, modern, fully responsive web application inspired by the popular **Status Saver - Video Saver** Android app (100M+ downloads).

This project brings the clean tabbed interface, fast saving experience, "view without seen" concept, and HD media handling directly to the browser using only frontend technologies.

## ✨ Features
- ⚡ Super fast status saving simulation
- 👀 View Without Seen emphasis
- 📸 Separate Images & Videos Tabs (just like the original app)
- 🎥 Built-in player simulation for offline videos
- 📱 Fully mobile-friendly & responsive design
- 🖼️ HD quality download flow
- 🔄 Multi-save and delete style UI
- 📤 Easy share & repost concept

## 🛠️ Tech Stack
- HTML5
- CSS3 (modern gradients, smooth transitions)
- JavaScript + jQuery
- Bootstrap 5.3
- Font Awesome 6

## 🚀 How to Run
1. Clone the repository
2. Open `index.html` in any modern browser
3. Paste a status link → Click **Save Status**
4. Enjoy the realistic processing animation and download
